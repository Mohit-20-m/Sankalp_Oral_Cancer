# Brand assets

The app name, tagline, colours and logo paths live in `src/config/branding.ts`. The image files are in
`public/brand/`:

| File | Use |
|---|---|
| `logo-full.png` | Full Arogya logo (mark + name + tagline), transparent background - login page |
| `logo-mark.png` | Symbol only, transparent background - sidebar, headers (on a light tile over dark surfaces) |
| `favicon.png`, `favicon.ico` | Browser tab |
| `app-icon.png` | Home-screen / touch icon (512 x 512) |
